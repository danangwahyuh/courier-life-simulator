# Courier Life Simulator 3D

Game simulasi kurir 3D open-world berlatar Indonesia, dirancang dengan pendekatan **mobile-first** dan ditargetkan berjalan di web/PWA.

## Status proyek

Proyek berada pada tahap inisialisasi. Target milestone pertama adalah *playable vertical slice* yang mencakup:

- Area gudang sebagai titik awal.
- Pergerakan karakter.
- Naik, mengendarai, dan turun dari sepeda motor.
- Mengikuti rute pengantaran.
- Serah-terima paket kepada penerima.
- Penyimpanan progres permainan.

## Arah teknologi

- React + TypeScript + Vite
- Three.js / React Three Fiber
- Rapier Physics
- GitHub untuk version control
- Cloudflare Pages untuk deployment web

## Prinsip pengembangan

- Prioritaskan pengalaman bermain di perangkat mobile.
- Bangun fitur secara bertahap dan jaga agar setiap milestone dapat diuji.
- Gunakan aset dengan lisensi yang sesuai dan dokumentasikan sumbernya.
- Pisahkan sistem gameplay, UI, dunia, dan penyimpanan agar mudah dikembangkan.
